🔗

1. Pega la URL

Copia el enlace del modelo o del archivo desde huggingface.co y pulsa Detectar archivos.

☑️

2. Elige archivos

Marca los archivos que quieras. Por defecto están todos seleccionados.

📁

3. Elige destino

Selecciona la carpeta con el botón Explorar. Los hilos se detectan automáticamente según tu CPU.

⚡

4. Descarga

Cada archivo se parte en trozos y se baja con varias conexiones a la vez. Si se corta, reanuda. Y se verifica SHA-256.

Detalles: la descarga usa peticiones HTTP Range para bajar un archivo en N trozos paralelos (uno por hilo), luego los une. Si un trozo queda a medias, en la próxima ejecución se reanuda desde donde quedó (resume). Cuando HuggingFace expone el hash SHA-256 del archivo, se verifica automáticamente al terminar. Todo funciona con Python estándar: cero dependencias.
Hecho con ❤️ para descargar modelos sin paciencia · solo necesitas Python 3.8+
